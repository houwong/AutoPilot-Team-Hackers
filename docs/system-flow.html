RUN SAFETY / 执行安全

重复执行防护与状态 / Duplicate Execution & State

Queue 控制自动处理；Command Center 保存可审计的执行记录。 / The Queue controls automatic processing; the Command Center keeps an auditable execution history.

同一 ticket 同时执行 / CONCURRENT RUN

同一个 ticket 被 Queue 同时处理两次：会被 active-run guard 阻止。
The same ticket cannot be processed concurrently by two Queue runs; the active-run guard blocks the duplicate.

重复点击 Run / DOUBLE CLICK

快速连续点击两次 Run：第二次返回 HTTP 409，不会创建第二个 active run。
Two rapid Run clicks: the second request returns HTTP 409 and does not create another active run.

未解决人工审核 / OPEN HUMAN REVIEW

同一个 ticket 不允许再次启动；它停在 Workbench 时，后续 pending ticket 可以继续运行。
The same ticket cannot start again; while it is parked in Workbench, later pending tickets may continue.

已处理 ticket / COMPLETED TICKET

Queue 会排除已经完成、blocked 或 rejected 的 ticket，不会自动放进新的 preview。
Queue excludes tickets already completed, blocked or rejected from future previews.

管理员重新处理 / ADMIN REPROCESS

直接手动指定已完成的 Target Issue Key 仍可能作为管理员 override 重新执行；受控的标准路径是使用 Requeue 并填写 reason。
A direct manual Target Issue Key can still be an intentional admin override; the controlled standard path is Requeue with a reason.

状态存放位置 / WHERE STATE LIVES

Supabase public.issues."Status" 是真实 ticket 状态；Command Center PostgreSQL 的 agent_runs、queue_items 和 queue_campaigns 保存执行状态与历史。
Supabase public.issues."Status" is the ticket source of truth; Command Center PostgreSQL stores run state and history in agent_runs, queue_items and queue_campaigns.
